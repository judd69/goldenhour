Hourly cloud cover, Open-Meteo. Amber bars fall inside a golden hour; periwinkle bars inside a blue hour.

Honest data. Sun times are the live sunrise-sunset.org reading for this place and date. Golden hour is sunrise → +60 min and sunset −60 min → sunset; blue hour is civil twilight ↔ sunrise/sunset — standard definitions, not a guarantee of good light. The quality score comes only from Open-Meteo hourly cloud cover; a clear sky can still be hazy. If either API is unreachable, this page says so instead of showing invented times.
